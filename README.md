# ミチシルベ（本番候補版）

**自分の悩みを解決し、自分の道を見つけるAI。**

Flutterアプリ + Rust/Axumバックエンド + PostgreSQL + Gemini API を使った、本番アプリ化を想定したプロトタイプです。

## このアプリが目指すこと

ミチシルベは、AIが進路や仕事を一方的に決めるのではなく、相談者が自分の悩みを整理し、自分の選択肢を考え、自分の道を見つけるための伴走AIです。

## 主な機能

- AI進路・将来相談（5ステップ）
- プロフィール・キャリアカルテ
- 適性・強みの分析
- AI模擬面接（STAR法）
- ZERO-CONTEXTモード
- 送信データの透明性確認
- 仮名化・プライバシー設定
- 会話ごとの削除、アカウント削除、緊急端末データ破棄
- 音声入力、添付ファイル
- AIプロフィール提案の確認・履歴

## 技術構成

- Mobile: Flutter / Dart
- Backend: Rust / Axum
- Database: PostgreSQL
- AI: Gemini API

Gemini APIキーはモバイルアプリに保存せず、Rustバックエンド側だけで管理します。
